# Luster Local

Sunoなどで作った完成済みの音源を、Mac内だけで解析・マスタリングするローカルツールです。音源は外部サービスへ送信しません。

## 起動（おすすめ）

Finderで **`Luster.app`** をダブルクリックします。ターミナルは開かず、通常のmacOSアプリと同じ専用ウィンドウで動作します。

- 起動ごとに空いているポートを自動選択するため、ポート競合しません
- 音源選択はmacOS標準のファイル選択画面です
- WAV保存はmacOS標準の保存画面です
- アプリを閉じると、内蔵サーバーと一時音源も自動的に終了・削除されます

従来のブラウザ版を使う場合は `start.command` をダブルクリックします。ターミナルからは、このフォルダで次でも起動できます。

```sh
npm start
```

表示されたURL（`http://127.0.0.1:...`）をブラウザで開き、音源をドロップしてください。終了は起動したターミナルで `Ctrl+C` です。終了時に一時ファイルも削除されます。

必要環境は Node.js 20以降とFFmpegです。導入手順は `SETUP.md` を見てください（Claude Code / Codexに任せられます）。

## macOSアプリの再ビルド

画面や処理コードを変更した場合は、次で `.app` を更新できます。

```sh
npm run app:build
```

アプリはApple Silicon向けにコンパイルされ、ローカル実行用のアドホック署名が付与されます。

## 処理内容

- 25Hz以下の不要な超低域を整理
- 温かさ、明瞭さ、空気感をEQと微細な倍音で調整
- フォーカスで90Hz〜16kHzを周波数ごとに監視し、混雑した成分だけを最大3dBの範囲で段階的に抑制
- Low / Low Mid / Mid / High Mid / Highの5バンド補正EQを再生中にリアルタイム試聴
- 全帯域コンプレッションは薄い「まとまり」用途に抑え、トランジェントを保護
- ステレオ幅の調整（モノラル音源には適用しない）
- オーバーサンプリング付きソフトクリップ
- EBU R128準拠の2パス・ラウドネス正規化とTrue Peak制御
- 48kHz / 24-bit WAVを書き出し

温かさ、明瞭さ、空気感、パンチ、広がり、密度は `0` が無加工です。プリセットの5バンド補正EQも初期状態ではフラットで、必要なときだけユーザーが追加します。

音源を読み込んだ時点で、上部プレーヤーの `A 原音` と `B 調整中` を切り替えられます。Bを再生しながら「フォーカス・温かさ・明瞭さ・空気感」、5バンド補正EQ、または目標LUFSを動かすと、その場で音が変わります。音圧感は入力LUFSとの差を使った近似で、±12dBの安全範囲とピークガードを通します。補正EQは基本の音色調整へ加算されます。フォーカスの5本の表示はEQではなく、各帯域の自動抑制量を示すメーターです。パンチ、広がり、密度と正確な最終LUFS／True Peakは、「この設定で仕上げる」を押した後の処理済み音源で確認します。

フォーカスのリアルタイム試聴は5帯域のWeb Audio処理、WAV書き出しはFFmpegのスペクトル・ダイナミクス処理を使います。書き出し時は入力LUFSに検出基準を合わせ、ステレオ音源ではMidを主に、Sideを弱めに処理して定位を守ります。試聴は操作感を揃えた近似で、最終品質は書き出し側が優先されます。

「解像度」は失われた音を復元する意味ではありません。元の圧縮音源に存在しない情報は戻せないため、聴感上の分離、輪郭、余裕を整え、再量子化時に高精度リサンプルとディザを使います。
